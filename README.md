# 📈 AI Stock Market Predictor Dashboard

An AI-powered stock market prediction and analysis dashboard built using Python, Streamlit, TensorFlow, and Plotly.
The application provides real-time stock analysis, interactive visualizations, technical indicators, and LSTM-based stock price forecasting.

---

# 🚀 Features

* 📊 Real-time stock market data
* 📉 Interactive candlestick charts
* 🤖 AI-based stock price prediction using LSTM
* 📈 Moving Average indicators
* 📦 Trading volume visualization
* 💹 Buy/Sell recommendation system
* 🌙 Professional dark-themed dashboard
* 🏢 Company information display
* 🔍 Search any stock symbol
* ⚡ Fast and responsive Streamlit interface

# ⚙️ Installation

## Clone the Repository

```bash
git clone https://github.com/your-username/AI-Stock-Predictor.git
```

## Navigate to Project Folder

```bash
cd AI-Stock-Predictor
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Application

```bash
python -m streamlit run app.py
```

The application will open automatically in your browser.

# 🧠 Machine Learning Model

The project uses:

* LSTM (Long Short-Term Memory)
* Sequential Neural Network
* Time-Series Forecasting

### Model Workflow

```text
Stock Data → Preprocessing → Scaling →
Sequence Creation → LSTM Training →
Prediction → Visualization
```
